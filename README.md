# Vhenj Kirby Solas — portfolio (Next.js + Framer Motion)

    npm install
    npm run dev      # http://localhost:3000 (redirects to /en)

Edit contact links, education, skills and location in `data.ts`. Empty values show `[Add ...]` placeholders.

## Deploy
Replace the old static files in your repo with this folder's contents (`git rm -r` the old ones first), commit and push. In Vercel the framework is detected as Next.js automatically; no settings needed.

## SEO
After deploying: add the domain in Google Search Console, submit `/sitemap.xml`, request indexing for `/en`. Use the same name "Vhenj Kirby Solas" on every profile and add those links to `CONTACT` in `data.ts`.
