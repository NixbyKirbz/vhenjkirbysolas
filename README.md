# Vhenj Kirby Solas — portfolio

Static site (plain HTML/CSS, no framework). All pages are generated by `build.py`.

## Edit content
Open `build.py`, change the CONFIG block at the top (contact links, education, skills, location, Search Console code), then run `python3 build.py`. Empty fields show a dashed `[Add ...]` placeholder on the page.

## Preview
`npx serve .` then open http://localhost:3000

## Deploy: GitHub + Vercel
1. Create a GitHub repo, then `git init && git add . && git commit -m "Portfolio" && git remote add origin <repo-url> && git push -u origin main`
2. On vercel.com choose Add New > Project, import the repo, leave Framework Preset as "Other", no build command, output directory `.`
3. Every push to `main` redeploys.

## Domain
Check `vhenjkirbysolas.com` is available before buying. Add it in Vercel under Settings > Domains and follow the DNS steps.

## Google Search Console
1. Add your domain at search.google.com/search-console (Domain property, verify with the DNS TXT record Vercel's DNS or your registrar accepts), or use a URL-prefix property and paste the meta-tag code into `GSC` in `build.py`, rebuild, push.
2. Submit `https://vhenjkirbysolas.com/sitemap.xml`.
3. Use URL Inspection > Request indexing on the home page.

## Ranking for your name
Use the exact name "Vhenj Kirby Solas" on GitHub, LinkedIn, Facebook and other profiles, and link each back to the site; add those links to `CONTACT` so they appear in the page's structured data.
